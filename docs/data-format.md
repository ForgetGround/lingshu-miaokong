# 数据格式

训练 CSV 使用宽表格式，每一行是一段固定长度 EMG 采样窗口。

## 必需列

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| `signal_0` ... `signal_199` | float | 单通道 EMG 窗口内按时间排列的采样值 |
| `label` | int | 类别编号 |

## 可选列

| 列名 | 类型 | 说明 |
| --- | --- | --- |
| `action` | string | 可读手势名称 |

## 标签

| label | action |
| --- | --- |
| 0 | `fist` |
| 1 | `relax` |
| 2 | `open` |

## 与 8 路 EMG 固件的关系

参考固件按 8 路 EMG 采样输出数据。当前训练脚本尚未直接消费 8 路多通道窗口，因此需要先做数据转换，例如：

- 选择其中一路 EMG 作为 `signal_0...signal_199`
- 对多路 EMG 做特征融合后生成单通道窗口
- 或扩展 `dataset.py` 和 `model.py` 支持多通道输入

## 采集建议

- 每个训练窗口长度固定为 200 点。
- 同一 CSV 内所有 `signal_*` 列应使用一致的采样率和单位。
- 训练前建议去除明显饱和、断线和强工频干扰样本。
- 当前训练代码会使用训练集均值和标准差对特征进行标准化。
